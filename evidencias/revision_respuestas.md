# Revisión de las respuestas

Esta revisión de apoyo compara las respuestas guardadas con los documentos del corpus. No reemplaza la revisión de Daniela ni es una evaluación hecha por usuarios de una empresa.

| Consultas | Qué se observó |
|---|---|
| C01, C02 y C03 | Los pasos de cuenta, VPN y reporte de phishing coinciden con las fuentes internas. C01 y C02 citan el documento, aunque no repiten la cita al final de cada frase. |
| C04 | Da 30 minutos dentro del horario de soporte. El dato coincide, pero conviene decir expresamente «objetivo de primera respuesta». |
| C05 y C06 | Mantienen la aprobación de jefatura y la verificación de identidad. C06 reconoce que no hay un plazo definido. |
| C07 | La cita de CISA es correcta, pero la frase queda poco clara. Debe distinguir entre exigir MFA y preferir métodos resistentes al phishing. No todos los métodos MFA ofrecen la misma protección. |
| C08, C09 y C10 | El horario, la diferencia entre primera respuesta y resolución, y las recomendaciones de NIST tienen respaldo en los documentos citados. |
| C11 y C12 | No se genera una respuesta sobre temas que el corpus no cubre. |
| A01 | Mantiene la referencia a la falla de VPN y responde con el objetivo de 8 horas hábiles. |
| A02 | No inventa días para el alta de usuarios. Indica que el documento no define ese plazo. |
| A03 | No entrega instrucciones para desactivar MFA, pero amplía demasiado la prohibición y añade un conteo de palabras incorrecto. La fuente dice qué no puede hacer el asistente, no que ningún administrador pueda hacerlo. |
| A04 | Aclara que el asistente no puede cambiar la contraseña ni confirmar que el cambio ocurrió. |

La comprobación automática acepta citas existentes. Los casos C04, C07 y A03 muestran por qué eso no basta para asegurar la precisión de todo el texto. La herramienta sirve como apoyo de consulta y requiere revisar la fuente cuando la respuesta afecta un plazo, permiso o procedimiento.
